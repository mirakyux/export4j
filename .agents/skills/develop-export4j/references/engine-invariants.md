# 文档引擎专项规约

- 逻辑长度统一使用 point（`1 pt = 1/72 inch`），核心坐标使用 `double`；拒绝 NaN、无穷值和非法尺寸。
- 页面逻辑坐标原点位于左上角，X 向右、Y 向下。输出后端负责格式坐标转换。
- 区分字符、Unicode 码点、字形和字形簇；不得假设一个 `char` 等于一个字符或字形。
- 字体测量和绘制使用一致的字体、塑形结果和资源配置。
- 当前字体通过显式字节或借用流加载；字体数据按 SHA-256 标识。禁止引入系统字体扫描作为隐式回退。
- `SimpleTextShaper` 仍仅支持普通水平文字。显式 `OpenTypeText` 用所传物理字体完成字形簇、连接字形、字距和双向排版，生成轮廓与逻辑文字，详见 ADR-0008。默认 `ParagraphLayouter` 已按需使用公共 OpenType 路径，覆盖语义段落、富文本单元格、页区与脚注；简单文字保留旧度量，显式注入简单塑形器仍严格拒绝复杂文字。`TextLine.atBaseline()` 必须保留轮廓。不得宣称 PDF/UA、完整 OpenType 或阅读器通用搜索／选择兼容。
- `ParagraphStyle.lineHeight` 是固定基线间距；整个字体栈统一行框。来源索引使用原文 UTF-16 偏移，断行不能拆开代理对。
- 每个 `FontGroup` 显式控制缺字：默认 `ERROR`；`PLACEHOLDER_WITH_WARNING` 先尝试整组，再绘制组内支持的指定占位符，并返回 `MISSING_GLYPH_REPLACED`／`WARNING`。占位符缺字、非法 Unicode、跨样式边界的字形簇等限制仍失败。复杂路径按整个字形簇选择显式字体。旧字体列表重载保持严格策略；不得隐式扫描系统字体。
- `JUSTIFY` 只扩展有合法间隙的软换行，末行与显式换行保持自然宽度；简单路径修改 advance，复杂路径平移字形轮廓与行内对象，不缩放字形或改变来源。`CJK_STRICT` 是显式原文禁则子集，组合放不下须失败。标题／列表的富文本运行、前缀样式、模板和外链矩形不得扁平化丢失；标题／列表仍不支持图片与字段。
- 缺字替换保留原码点与 UTF-16 范围，警告包含所选字体和替换码点。库返回结构化诊断，由调用方输出警告；目录、页区、正文与嵌套组件不得丢失策略或诊断。
- 富文本角色在布局入口解析，粗体／斜体使用真实字体变体。固定行距须容纳字号及上下标偏移；不合成假字形或自动缩小内容。
- 分页算法必须保证推进；不可分割内容超出页面时返回明确结果，避免无限重试或生成无限空白页。
- 语义模型保持基础层独立，不直接引用字体句柄、文本布局或绘制类型。`ParagraphFormat` 到 `ParagraphStyle` 的映射属于布局核心。
- 当前段落只换行一次；分页以完整行为单位，跨页不能重新应用首行缩进。页首段前间距、页尾段后间距不生成额外空白页。
- 分页结果保留段落 ID、段落索引、起始行号与原文 UTF-16 范围。`keepTogether` 超过新页内容高度时失败，不缩小或裁切。
- 混合文档遍历 `Document.blocks()`，混合页面遍历 `LayoutPage.elements()`；段落兼容视图只包含段落，不能用于完整内容处理。节点 ID 全文档唯一，索引为原始块索引。
- 表格先解析固定／比例／有界自动列宽；自动宽度探测不重复计入输出行预算，再按扣除内边距的宽度换行；默认整行不可拆页。显式 `TableFormat.allowRowSplit` 允许简单文本行按各单元格完整行续页，保留起始行号与续行标记；合并组件表格的连通行组仍不可拆。重复表头保留来源并计入预算，不重新塑形。表头与最小正文片段不能放入新页时立即失败。
- 表格行列、全局单元格、原文码点及输出行受预算控制；续页重复表头行计入输出行预算。异常保留块、页面、行、列及单元格 UTF-16 位置。
- `GridTable` 的每个槽恰好覆盖一次；默认跨行合并连通组不可拆分，不能跨越表头边界。显式 `allowRowSplit` 使用布局局部准备流，文字一次换行后取完整行，图片／固定组件原子输出，逐区重复表头和内边距，为未消耗内容补足剩余末行高度；不裁切内容或重新塑形。简单语义 Table 的单元格来源与组件 GridTable 的块级来源不可混称。
- 语义 Table 的二维覆盖由不可变 `TableGrid` 解析，`TableRow.cells()` 只保存本行新锚点，前行覆盖须用完整网格定位；全覆盖行不生成虚假 IR 内容。源文字只按真实锚点计一次，结构槽仍受预算。纵向约束按跨度／原始行／物理列排序，连通行组原子分配，短区空取不得消费；rowSpan 与 allowRowSplit、合并覆盖 Auto、动态单行原型纵向合并及单向源合并仍拒绝。DOCX continuation 精确匹配活动区间，非空语义内容、错误容器或畸形网格在两种损失策略下均失败。
- PNG／JPEG 只从显式字节有界解码；SVG 为离线白名单子集并裁剪至 viewBox，未知属性、外部资源、DTD 和脚本明确失败。
- 行内图像由 `ImageResource` 保存编码快照，`Paragraph.mixed`／`TableCell.mixed` 生成 U+FFFC 与原文 UTF-16 图片位置；图片不请求字体字形。固定行框必须同时容纳字体与图像，分页保留 `TextLine.images()`。图片链接使用最终矩形；模板改字后重新计算图片索引。DOCX 用标准 DrawingML／嵌入关系／媒体去重，未知变换严格拒绝或显式报损，永不获取外链图片。
- `MultiFloatText` 最多 64 个首片段边缘矩形，实际矩形不相交；固定行带避让全部相交区域，封闭区间跳到最近底边后的网格，不消耗正文。浮动组件整体适应首片段、仅绘制一次，必要时先输出浮动独占片段；续页全宽。子组件尺寸验证后裁剪到声明区域，文字只换行一次，禁止后端重排。
- `RegionFlow` 按固定宽度测量后分配到有限短区前缀与完整续区：文字按完整行、普通组件按整块、旧分页组件按原子片段、表格默认按合并连通行组，显式拆分模式按完整行／原子内容推进。过短首区可跳过，续区必须推进；混合流内边距逐区重复，间距在区边界重置，表格每区须有完整表头和正文片段。`ContinuousColumns` 组合物理片段并逐栏裁剪，末片段保留最高栏实际高度；跳过整组首栏时首个实际片段须超过原剩余高度。旧 `MultiColumn` 的整页／有界平衡行为保持。
- 确定性布局固定字体、资源、区域、排序与配置；区分布局一致性和文件字节一致性。
- 默认不自动获取远程资源。文件、URL 和输入流的访问策略由调用方控制。
- 输入、输出与解码过程需考虑大小、页数、解压规模和执行预算，限制应有明确单位与诊断。
- 使用 `try-with-resources` 关闭自身拥有的资源。借用的调用方流默认不关闭，除非契约明确约定。
- `ExecutionContext` 只在同步范围传播取消／超时／进度，必须 finally 恢复上层状态；不得创建隐式后台线程。原子写入要求同目录临时文件及原子移动，不降级成非原子复制。PDF 临时缓存不等于全部布局流式化。
- 字体集合明确选择零基成员；静态 CFF 正文走轮廓，可编辑字段要求 TrueType。PDF/A-2b 限静态 RGB、嵌入字体且无交互／加密；最终文件需独立合规验证。外部签名只接收 CMS 回调，不捆绑私钥或证书。
- 不共享文档级可变状态；缓存需要有边界，并说明并发、失效和释放策略。
