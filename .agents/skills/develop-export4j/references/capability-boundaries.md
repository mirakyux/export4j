# 能力边界与证据入口

这些条目用于定位既有能力，不代替当前源码、支持矩阵和对应验收记录。实现变化时同步相关条目；历史阶段编号仅标识证据，不表示未来任务状态。

- 项目定位：Java 文档生产引擎，核心竞争力是语义模型、布局算法与可替换后端。
- 能力概览：PDF 报告支持显式 OpenType 文字、多栏、矩形绕排、文本表格拆行、脚注续页、换行引用、Builder、样式继承及上下文诊断；另有 SVG／PNG 静态输出、DOCX 语义子集、BOM／SBOM 和隔离 Maven 调用方。工程含 17 个模块；具体边界与证据以[支持矩阵](../../../../docs/capabilities-api.md)、下列 API 和对应验收为准。
- 项目名为 Export4j；Java 根包名与 Gradle 项目 group 为 `com.mirakyux.export4j`，模块及制品使用 `export4j-*`。
- 后续已补齐行内 PNG／JPEG、共享图文换行／分页、表格图片续页、图片外链与标准 DOCX 媒体，最新范围见[图像 API](../../../../docs/inline-images-api.md)和[验收](../../../../docs/verification/phase-6-inline-images.md)。
- 多矩形绕排已补齐首片段左右并存、错位／堆叠、封闭行带跳过和整体移页，续页恢复全宽，见[多浮动 API](../../../../docs/multi-floats-api.md)和[验收](../../../../docs/verification/phase-7-multi-floats.md)。
- 当前页连续文字分栏已补齐首组短栏、完整续栏、最低行数移页及正文接续，标准子组件为 `FlowText`／`OpenTypeText`；见[连续分栏 API](../../../../docs/continuous-columns-api.md)和[验收](../../../../docs/verification/phase-8-continuous-columns.md)。
- 混合流和表格已通过 `FlowColumn`／`GridTable` 接入连续区域，支持图片整块移动、嵌套内边距、逐栏重复表头和完整合并行组；见[混合分栏 API](../../../../docs/mixed-columns-api.md)和[验收](../../../../docs/verification/phase-9-mixed-columns.md)。
- 正文段落已支持固定宽度 `InlineField`，解析最终页码／总页数／目标页码／编号和注释标记，脚注跟随实际标记所在行；见[行内字段 API](../../../../docs/inline-fields-api.md)和[验收](../../../../docs/verification/phase-10-inline-fields.md)。语义表格进一步支持字段、逐页表头值和拆行续页，见[阶段十一验收](../../../../docs/verification/phase-11-table-fields.md)。
- 技术基线：Java 21 LTS、Gradle 多模块、Kotlin DSL、自研代码采用 Apache-2.0。
- DOCX 原生四类页码／引用字段已支持标准导出、简单／扁平复杂字段导入及显式预留宽度；Word 16.0 字段样例已验证，见[阶段十二验收](../../../../docs/verification/phase-12-docx-fields.md)。不保证一般 Word 文档无损互转或与 PDF 分页一致。
- 常用 Builder 已支持自动 ID、默认正文、列表、等宽文本表格及原子路径输出；富文本标题／列表、两端对齐及可选严格中文禁则见[编写指南](../../../../docs/authoring-api.md)与[阶段十三验收](../../../../docs/verification/phase-13-authoring.md)。有界混合报告已采样独立 JVM 的 Windows 工作集、私有字节和句柄，不等于长期容量或无泄漏证明。
- 公共编写和配置现已推广链式构建，组件文档使用 `Documents`，合并表格按行声明并支持最小行高，默认页区与链式导出接入 `DocumentEngine`；见[链式 API](../../../../docs/fluent-api.md)和[阶段十四验收](../../../../docs/verification/phase-14-fluent.md)。`GridTable` 行高先满足单行约束，再按跨度／行／列固定顺序满足合并约束，几何不依赖格声明顺序。
- 依据[能力缺口表](../../../../docs/capability-gaps.md)逐项自主推进；普通列 `.text()` 现在自然续页，固定文字使用 `.fixedText()`。组件网格使用 `.grid()`；显式 `allowRowSplit(true)` 支持合并格完整行与混合图片续排，默认仍整组移动，见[续页指南](../../../../docs/grid-continuation-api.md)和[阶段十五](../../../../docs/verification/phase-15-continuation.md)。不复制竞争项目实现、注释或测试。
- 通用静态表单提供 `FormText`／`ChoiceGroup`／`CheckMark`／`LabelValue`／`FillLine`；标记采用自研矢量，复用共享文字布局及标准合并格续页。定位 `TableComponent` 明确拒绝字段、外链和具名字体角色，见[静态表单 API](../../../../docs/static-forms-api.md)及[阶段十六](../../../../docs/verification/phase-16-static-forms.md)。语义表格区域流使用下述独立入口。
- 组件语义 IR 使用有序 `SemanticPlacement` 保存 Table 源、测量片段及实际字体策略；组合器须使用 `ComponentSemantics.append`，包含语义内容时旧 `commands()` 明确失败。`SemanticTable`／`.semanticTable(Table)` 已接入区域流、逐栏表头字段及显式完整行拆分，详见[语义组合 API](../../../../docs/semantic-components-api.md)和[阶段十八](../../../../docs/verification/phase-18-semantic-table-flow.md)。长合并格与合法缓存语义表头已由[语义格 API](../../../../docs/grid-semantic-flow-api.md)、[ADR-0024](../../../../docs/adr/0024-grid-semantic-cell-flow.md)及[阶段二十](../../../../docs/verification/phase-20-grid-semantic-flow.md)补齐；固定调用仍单片段，独立重复源和 DOCX 嵌套仍拒绝。
- 默认文字样式由 `ComponentContext`／`StyleScope` 传播，文字 Builder 用 `TextInheritance` 显式记录六项属性声明，颜色独立；不得按 12 pt、零缩进或 LEFT 等数值猜测意图。具名 setter 只改对应项，逐项恢复保留其余声明；旧构造器与 `.style(value/callback)`／格 `.textStyle(value)` 仍完整显式。字号不暗中扩大继承行距。`Documents.bodyFormat`、网格默认值及 `toBuilder` 保留加入时快照；网格／绕排直接测量前必须解析，作用域保留原子宽度、短区、语义来源及诊断。见[样式 API](../../../../docs/style-defaults-api.md)、[ADR-0030](../../../../docs/adr/0030-property-text-inheritance.md)与[阶段二十三](../../../../docs/verification/phase-23-property-styles.md)。
- 离线 XML／Markdown 由 `export4j-adapter-template` 编译到既有 DocumentTemplate，生产仅依赖模型与 JDK。XML 支持变量／条件／循环／动态行、四类固定宽字段、1～9级十进制编号和静态图文外链；Markdown 为严格轻量子集。资源显式注册，全部分支编译检查，两层预算保持；见[XML](../../../../docs/xml-template-api.md)、[Markdown](../../../../docs/markdown-template-api.md)及[阶段二十二](../../../../docs/verification/phase-22-text-and-adapters.md)。HTML/CSS、递归 include、动态 URL／目标和设计器仍开放。
- 六脚本两路径文字语料已核对簇、双向续行与连字一致性；12 项 PDFium 查询／选中文字精确，11 项 pypdf 提取及约 0.519 pt 轮廓选区仍有限。簇按原文／实际字形边界约束，缺字准备与空行均有预算／取消；见[文字语料](../../../../docs/text-corpus-api.md)与 [ADR-0026](../../../../docs/adr/0026-source-clusters-and-shaping-context.md)，不宣称完整 OpenType／UAX #29 或通用阅读器兼容。
- 独立 `export4j-adapter-pdf` 只处理受限静态页，内部复用 PDFBox，公共签名不泄漏其类型。输入快照／预检、选页／合并、显式 owner 解密复制、损失诊断及原子输出见[PDF API](../../../../docs/pdf-adapter-api.md)；交互、签名、标签、未知滤镜等明确拒绝。不得将 PDFBox 延迟对象解析吞掉的 IOException 当作成功；owner 身份不只由权限位判定；预算不等于恶意输入沙箱或硬 RSS 上限。
- 单向长表采用独立 StreamingTable／TableRowSource，不包装完整 Table；布局只保留有限表头、当前页和一个待放置行，DocumentPainter.paintPage 到 PageBackend／PageWriter 同步交付。源工厂导出时打开并由引擎关闭，源先关闭再 finish，close 不隐式完成；请求配置在 to 入口快照，返回扁平计数及同步诊断。固定列普通／纯富文本整行分页已由[阶段二十九](../../../../docs/verification/phase-29-streaming-rich-text.md)验收，真实字体角色及格／行运行预算保留；链接／图片／合并／未来字段／交互／配置页区等明确拒绝；PDFBox 页树仍增长。见[长表 API](../../../../docs/streaming-table-api.md)、[ADR-0031](../../../../docs/adr/0031-single-pass-table-output.md)与[阶段二十四](../../../../docs/verification/phase-24-streaming-tables.md)。
- 语义 `TableCell.columnSpan`、Java／XML 绑定与标准 DOCX `gridSpan` 已贯通；源格为真实锚点，IR 列号为物理起始列，合并宽度扣一次 padding。覆盖 Auto 列及单向长表合并仍拒绝；见[列合并 API](../../../../docs/column-spans-api.md)与[阶段二十五](../../../../docs/verification/phase-25-column-spans.md)。Word 读取／字段更新和保存回读须分开登记。
- 语义 `rowSpan`、二维 `TableGrid`、全覆盖空锚点行及标准 DOCX `vMerge` 已验收；行按真实锚点编写，纵向连通组整体移页／移区，字段及图文链接保留原始物理列。见[跨行 API](../../../../docs/row-spans-api.md)与[阶段二十六](../../../../docs/verification/phase-26-row-spans.md)。
- 有界块格与原子内表已通过[阶段二十七](../../../../docs/verification/phase-27-block-cells.md)：链式 Paragraph／Table 顺序、两层表深、全树来源与共享预算、字段／锚点／图文外链和标准 DOCX p/tbl/p。XML 可直接 p／table／p，并在所有分支编译校验，Each／Rows 保留同副本引用，见[XML 块格 API](../../../../docs/xml-block-cells-api.md)及[阶段二十八](../../../../docs/verification/phase-28-xml-block-cells.md)。递归续排、纵向拆组和一般 Word 保存回读仍开放。
- Java 编写时主题已由[阶段三十](../../../../docs/verification/phase-30-authoring-themes.md)验收，调用见[主题指南](../../../../docs/themes-api.md)。DocumentTheme 只持模型完整值，内容加入时快照；toBuilder 保留格格式显式意图。显式 Block／Cell／InlineStyle 不重写，组件沿用六项继承；XML主题与p／span静态名称已通过[阶段三十一](../../../../docs/verification/phase-31-xml-themes.md)，保留XML body／cell独立范围与size行高规则。全局颜色／角色和页区主题仍开放；目录独立样式见下项。
- 平面离线 XML include 已由[阶段三十三](../../../../docs/verification/phase-33-offline-xml-includes.md)验收，见[片段指南](../../../../docs/xml-includes-api.md)：仅显式 String 登记，全树 prefix 唯一，局部 ID／列表限定，循环编号连续；跨 owner 派生列表碰撞拒绝。总输入含全部登记源，解析和展开分别计费；片段叶通过 fragmentName 定位，message 保持脱敏。递归／文件／网络加载仍拒绝。
- XML 多级 numbered 已由[阶段三十五](../../../../docs/verification/phase-35-xml-numbering.md)验收，见[指南](../../../../docs/xml-numbering-api.md)：静态level=1..9且默认1，编译全部分支；父计数和溢出由实际展开后的SemanticBlocks／DOCX检查。each不重置list-id、include按prefix隔离，引用保留完整点分值；numbered内link／字段／图片仍拒绝。
- Java 根包名统一为 `com.mirakyux.export4j`，源码目录与包声明一致，测试、示例及文档导入使用同一命名空间。Gradle 项目 group 同步使用该值；正式发布仍需验证命名空间权限。
- 四类 PDF 可编辑字段显式 FormStyle 已由[阶段三十二](../../../../docs/verification/phase-32-editable-form-styles.md)验收：属性设置意图、旧默认、完整字体及全部 AP 状态保持。零框须同时无实际描边；小于 0.0001 pt 的正绘制值拒绝；固定字号不保证内容完整放入控件。自动填写／保存不等于人工阅读器验证，见[指南](../../../../docs/form-styles-api.md)。页区主题仍独立，目录子集见下项。
- 目录独立 ContentsStyle 已由[阶段三十四](../../../../docs/verification/phase-34-contents-styles.md)验收，见[指南](../../../../docs/contents-styles-api.md)：标题／页码完整排版、三色与显式意图；未声明值按当前条目重派生。行框先预留，真实页码固定48 pt且只准一行，不请求虚构探测字形。旧三参源码入口保留，record组件兼容边界单独记录。
- XML 静态页面配置已由[阶段三十六](../../../../docs/verification/phase-36-xml-page-settings.md)验收：根首个空 `page`、静态 A4／LETTER 或成对宽高、方向与边距，严格十进制 pt／mm／cm／in；未声明项采用 Java 默认。原主源首位、引用片段／全分支拒绝、解析／展开预算与脱敏保持；page不占Block／ID，DOCX页面按整数twip量化。后续修改运行 `build sbom publishLocalBundle :examples:xmlPageSettings`、隔离调用方与 `scripts/verify_xml_page_settings.py`，回归XML／include／字段／主题；全部新页双渲染及逐页复查。
- 固定页区字体角色已由[阶段三十七](../../../../docs/verification/phase-37-page-region-fonts.md)验收，见[指南](../../../../docs/page-region-fonts-api.md)：Renderer入口固定同次角色快照，PageComposer四参重载传入header／footer／background／foreground；旧无角色重载保留空映射。默认字体及StyleScope／FontScope保持，标准TextComponent选角色仍需自定义委托；固定多片段和SemanticTable拒绝不放宽。修改运行 `build sbom publishLocalBundle :examples:pageRegionFonts :examples:componentPdf :examples:advancedPdf :examples:production :examples:capabilities`、新调用方与 `scripts/verify_page_region_fonts.py`，并回归默认样式／主题／目录／字段；全部新页双渲染和逐页复查。完整默认角色／颜色级联及XML页区仍开放。
- 已采用 Gradle 9.2.1、PDFBox / FontBox 3.0.8 和 JUnit 6.1.3。OpenType／静态输出使用 JDK java.desktop，DOCX 使用 JDK ZIP／安全 XML；实际依赖见版本目录和锁文件。

## 字体、列表与 XML 默认值

当前已补齐[组件字体作用域与固定富文本](../../../../docs/component-text-api.md)、[独立列表标记样式](../../../../docs/list-markers-api.md)及[XML 默认字体／颜色](../../../../docs/xml-text-defaults-api.md)，证据见阶段三十八至四十。FontRoleScope 选择完整 FontGroup；RichTextComponent 的运行样式为完整显式值，段落继承只影响几何且整体原子。列表 markerStyle 不从首个正文运行推导，toBuilder 保留完整值，显式 defaultMarkerStyle 才重新派生。XML TextDefaults 与主题几何独立，body／heading／cell 分域，role="" 和黑色按存在性覆盖；命名 span 完整替换、内表重起全局 cell 默认。报告／静态表单试用判断见[就绪评估](../../../../docs/readiness-assessment.md)，开放项继续如实登记。

- [HTML／Markdown 导出](../../../../docs/web-export-api.md)直接消费语义模型；全局／逐功能 ERROR、WARN、IGNORE 不压制非法输入、预算、取消与 I/O。HTML/CSS 输入保持独立，证据见[阶段四十三](../../../../docs/verification/phase-43-web-exports.md)。
