# 项目规约维护规则

本目录遵循根 [AGENTS.md](../AGENTS.md)。修改共享规则前阅读对应技能；新增或调整笔记还须阅读 [notes/AGENTS.md](notes/AGENTS.md)。

- 只保留跨环境可用的项目规则、工程决策和仓库相对引用。
- 不写入个人路径、机器配置、凭据、对话、会话授权、代理分工或原始执行日志。
- `SKILL.md` 使用 `name`、`description` 两项 YAML 元数据；名称与目录一致，描述说明触发场景。项目检查器按这个简化格式验证。
- 技能正文负责行动步骤，`references/` 保存按需阅读的技术细则，避免多处维护同一份契约。
- 已有架构决策继续维护在 `docs/adr`；笔记不得复制一份独立的架构事实源。
- 不在规则中加入自动提交、推送、发布、外部通信或强制代理委派。
- 修改后运行 `python .agents/scripts/verify_rules.py`；新增检查逻辑须验证它既接受合法输入，也拒绝对应的错误输入。
