# 工程笔记规则

遵循根规则及 [agent-notes](../skills/agent-notes/SKILL.md)。本目录只记录项目工程取舍。

- 路径格式：`<生命周期>/<类别>/yyyy-mm-dd-topic.md`。生命周期与类别由 [manifest.json](manifest.json) 定义，状态以路径为准并与正文一致。
- 默认检索相关 `implemented`；`proposed` 不代表已实施，`rejected` 不代表通用禁令，`archived` 不代表当前有效。
- 使用中文结论及真实证据，按模板写明问题、决定、备选、后果／验收风险、验证与适用范围。
- 重大架构决定以 `docs/adr` 为唯一权威；API 和验收各归其原有文档，不复制完整手册或阶段流水账。
- 同主题优先更新；状态转换移动文件并更新引用。归档条目必须链接替代规则或解释失效原因。
- 只按需建立有实际笔记的类别目录；不为占位增加假提案、假结论或空分类。
- 不记录个人信息、机器路径、凭据、会话状态、代理分工或原始日志；命令、来源与证据使用仓库相对位置。
