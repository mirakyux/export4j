# 工程笔记：跨入口规则与操作上下文收敛

状态：已实现

## 先说结论

保留统一语义／布局／绘制分层，将跨目标共用的纯规则、操作期绑定和静态语法计划集中维护。六项处理已落实，源码研究及原问题见[架构研究](../../../../docs/architecture-reference-review.md)，构建和输出事实见[接入验收](../../../../docs/verification/architecture-convergence.md)。不增加永久可变文档上下文或第二套分页引擎。

## 问题

DOCX 原始权重求和／乘法让合法 `1e308` 比例溢出，单列甚至错误成功并写出饱和值。starter 的字体声明在输入解析、PDF 与 Word 中重复投影；完整／逐页准备、相同 XML 的结构解析以及 bytes 字体命中前的快照／摘要也有重复工作。参考项目提供了装配与生命周期经验，不能用其运行对象边界替代本项目契约。

## 决策

- `RelativeWeights` 只共享有限正相对数快照及分配。归一化与补偿求和避免溢出和分母舍入偏移；分栏保留乘 share 顺序，表格保留归一化后乘除顺序。subnormal 结果按最小 double 单位精确 HALF_EVEN 舍入，拒绝舍入为零的份额，避免中间浮点或有限精度十进制近似使半单位边界翻转；独立份额舍入不承诺总和严格守恒。固定／Auto／padding／单位舍入／预算各归原层。
- starter 的 `OperationFonts` 按输出形成不可变绑定，同一来源对象只载入一次。稳定业务角色使用明确真实变体；可借用不可变 PDF 后端与有界解析池，不接管外部缓存关闭。
- `PreparedSemanticDocument` 共享语义准备，不共享完整 IR 的生命周期；逐页继续紧凑证明与重放。
- XML `Syntax` 是用户拥有的静态结构计划，片段按 prepare 时展开。它不捕获内容 parser 或已加载字体；compile／render 重新使用当前配置、资源、数据快照、预算与会话。
- 私有 bytes 来源一次隔离并复用内容标识；外部数组入口仍复制，文件／资源仍重读。字体冷解析移出锁，有限 pending 同键合并；clear／close 撤销旧解析的驻留资格，不使它重新填回缓存。
- 内部测量 scope 恢复临时计费标志、来源路径与需要恢复的行数，覆盖异常和取消，不拆成多个分页协调者。

## 考虑过的备选方案

- 逐处修相对宽度：短期改动较少，但已发生规则漂移；选共享纯规则，避免 DOCX／公式反向依赖布局内部对象。
- 保存全局 Session／完整运行模板／反射计划：引用与预算边界难以说明，不采用。对象绑定快照继续遵循[既有取舍](../../implemented/feature/2026-11-14-template-object-snapshot.md)。
- 为共享准备而先收集所有页面：破坏逐页保留边界，不采用。
- 永久保留字体或覆盖 FontBox 同包类：既有已否决方案不重启；优化发生在已有显式来源和有界缓存入口。
- 为 cold miss 设置无界 Future 表：把压力转成全局驻留，不采用；超出协调容量的合法输入按次解析，不因为缓存满而拒绝字体。

## 后果

输入装配和相对数规则有统一维护点，计划可显式复用且不改变隐式资源策略。公开底层 `load(byte[])` 为隔离仍需复制。bytes 来源仍持有编码快照；TTL 只释放缓存引用，调用方、来源或活动租约存在时不能保证 GC。冷解析不再持有缓存大锁，仍有瞬时 parser 和 snapshot 分配，不代表进程峰值或 RSS 有稳定降幅。

纯语法准备不是完整语义编译，资源键与语义错误仍可能在 compile 暴露。局部测量不外推全部模板、全部字体格式或整篇导出性能。PDF 与 DOCX 各自的字体与布局契约保持，后端不参与重新换行。

## 验证

本轮增加极端比例与字形边界、共享准备错误／预算、语法计划配置／并发／取消、缓存同键／异键／失败／clear／close／调度，以及稳定角色与后端借用回归。受控探针分别记录 compile＋render 和热命中的主线程分配，未把局部计时解释为整篇性能。实际通过数、制品消费、独立结构／渲染与未执行阅读器动作统一见[验收记录](../../../../docs/verification/architecture-convergence.md)。原始证据保留在忽略目录 `build/verification/architecture-fixes-20261119/`。

## 适用范围

涉及 model 纯值计算、starter 装配、components 准备、模板、字体缓存及布局临时状态。不修改消费端业务、引入隐式字体／外联资源、增加新后端，或改变 PDF 文档对象归属。公共入口和资源所有权以对应 API／ADR 为准；重大边界变化另记 ADR。
