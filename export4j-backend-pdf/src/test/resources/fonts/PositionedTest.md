`PositionedTest.ttf` is an original geometric font under Apache-2.0, generated by
`scripts/create_positioned_font_fixture.py` with fontTools from the verification
requirements. It contains rectangular A/B glyphs with different widths and an
intentional GSUB A → B substitution. Tests verify that the PDF backend preserves
already measured glyphs instead of applying this substitution a second time.
It is a test resource only and is not included in library artifacts.
