# 阶段一百一十二：设计器工作区与交互整理

## 实现范围

设计器采用统一的文件命令、文档工具栏、结构导航、连续画布和上下文属性检查器。结构树显示中文类型、实际文字与 ID，支持搜索、折叠和键盘导航；表格及行、列设置按层展开。节点属性按用途分组，ID 和正文靠前，多选差异显示“多个值”。文件菜单、插入菜单、操作搜索、导出任务和帮助使用一致的控件与焦点反馈。

`Ctrl+K` 搜索可执行操作；专注模式隐藏两侧面板。编辑视图写入地址参数，支持重新打开相同视图。备用字体诊断按类别归并，保留原始记录；草稿错误同时出现在编辑区与状态栏。源码高亮、实时 Java 预览、多选排序、资源、表格工具与损失策略继续使用现有契约。没有改动文档模型或排版后端。

操作入口见[设计器指南](../designer.md#工作区导航)。
