# 阶段五十五：新建图片 PDF 的区域脱敏

设计见 [ADR-0063](../adr/0063-fresh-raster-pdf-redaction.md)，调用见 [API](../pdf-redaction-api.md)。复现命令与[阶段五十四](phase-54-pdf-text-editing.md)共用样例任务及独立验证器，结论单列。

5 项新增脱敏行为验证原文字／字体／元数据／附件／历史不复制、真实文字和源图片像素删除、旋转 CropBox／UserUnit 规范化、禁止漏页或保留不支持的原对象、区域／像素预算、取消和旧目标保持。PDF 模块总计 104 项通过，无失败、错误或跳过。

独立解析所有输出对象和解码流，确认没有 SECRET 原数据；输出单次 EOF、无文字／字体／批注／附件／源元数据，每页只有清理后的 RGB 图像且无隐藏 SMask。独立像素检查文字区域和原蓝色图片区域均已变为实黑，选区外内容保留可见。共 7 页输入／输出及隔离调用方结果用 Poppler／PDFium 5.13 双渲染并全部查看。

区域内必须为精确填充值；区域外原矢量与光栅结果分别由不同引擎绘制，使用已有跨引擎渲染质量界限，不能把不同抗锯齿要求为逐像素恒等。该限制不放宽区域内清除及原对象不存在的断言。

本实现明确损失全文搜索、文字和矢量编辑能力，不提供保留其余文字可编辑的内容流选择性脱敏，也不自动寻找其他可见敏感副本。调用方必须登记所有待清除区域；OCR 不在范围内。
