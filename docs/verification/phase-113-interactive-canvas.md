# 阶段一百一十三：画布直接编辑与双模式

## 实现范围

设计器画布接入 React／TypeScript 与 ProseMirror，继续编辑同一份 XML 和资源包。默认“便捷编辑”呈现模板原文及变量标记，活动输入保留浏览器草稿，完成编辑后更新引擎分页；“精确排版”呈现绑定测试数据后的 Java 引擎结果，输入经防抖刷新。切换模式不替换活动编辑 DOM，也不改变源码、资源或撤销记录。

画布支持正文、富文本和行内单元格直接输入，单段页眉／页脚编辑，框选、多选、组移动、坐标及尺寸属性、缩放／旋转手柄和 PNG／JPEG 粘贴。自动占位／固定位置是组件属性；默认组件及新粘贴图片参与正文流，拖动显示插入线并排序，不隐式转换为固定框。动态表格、列表和循环／条件按整个语义模板排序，同级多选保持源码顺序。拖柄、上移／下移按钮和 Alt+方向键提供等价入口。

顶层段落、图片段落和表格可显式转换为固定框，保留有效段落样式；框支持固定、剩余空间填充和内容自动高度，以及文档物理页选择。只有固定组件显示“遮盖正文／上下避让”：前者保留正文原布局，后者在 Java 引擎中保留上方内容、排除相交的纵向区间，再从下方续排。固定恢复为自动占位时使用附近正文位置。ID 保持属性第一项，组件排版属性紧随其后。

同页相邻的普通段落和标题共用连续文字编辑区，支持跨段光标、选区和段落合并；变量、字段、链接和 XML 对象保留原结构。选区附近显示浮动格式工具条，折叠光标时隐藏；块旁提供前／后插入和组件菜单，插入段落后直接编辑新内容。连续输入和拆段使用稳定 ID，混合文字格式写成合法的单层 span。合并及动态表格单元格从 IR 几何映射回模板，绑定结果不覆盖模板表达式。

结构和几何修改先更新画布与源草稿，再异步校准 Java 版式；服务返回前仍可选择、编辑及撤销，旧响应不覆盖后续修改。拖动显示移动预览、占位框或固定对齐吸附线；文字提交、组件插入、排序和几何修改进入工作台操作历史。复制和删除遵循组件外框，单元格编辑完成后操作整表；循环副本保留绑定并重映射其内部引用。设计和边界见 [ADR-0107](../adr/0107-interactive-template-canvas.md)及[操作指南](../designer.md)。

## 边界

便捷模式是近似文字显示，精确分页及导出以 Java 引擎为准；直接输入时的活动文字编辑层仍由浏览器排版。此次中文输入检查使用浏览器 insertText 和编辑 DOM 保持断言，未验证每种操作系统输入法。同页相邻普通段落和标题可连续编辑；跨页段落明确提示“跨页段落 · 编辑完整原文”，不把单页片段的点击位置当成完整原文的精确光标位置。复杂页区、嵌套模板及未提供直接命中的结构继续通过属性／XML 编辑。

便捷编辑的临时让位只作用于同页后续正文，页脚保持固定。新增行造成的真实分页在完成编辑或精确预览时由 Java 重新计算，浏览器临时位置不作为导出几何。

固定对象的上下避让覆盖正文全宽，不提供对象左右环绕；组缩放对各对象应用相同尺寸增量，不承诺完整成组变换。生成目录与指定物理页或上下避让组合明确拒绝。DOCX／HTML／Markdown 的几何映射继续执行各格式既有损失策略。此次没有实际运行远端 CI、跨平台浏览器或正式发布，也不据此扩大平台兼容矩阵。
