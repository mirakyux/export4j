# Export4j 0.1.0-rc.3

本页记录 RC3 相对 RC2 的变化及发布前本地证据；正式发布日期、签名制品和远端消费结果以[发布规范](../releasing.md)中的实际记录为准。Java 基线仍为 21，16 个库与 BOM 统一版本；源码默认构建继续使用 `0.1.0-SNAPSHOT`。

## 主要变化

- `DocumentEngine` 可以携带不可变的布局及组件预算默认值，普通导出、逐页导出、块源、重放和目标转换继承这些值。单次请求可明确覆盖，修改一个请求不影响复用引擎或其他请求。专用长表入口继续使用自己的预算。
- PDF 普通 TrueType 文字分别管理 Unicode、CID 和实际 GID，修复不同 Unicode 共用一个字形时提取原文混淆的问题。普通、逐页及 spool 路径保留原文与显式字距；编码容量耗尽时另建字体资源，补充平面码点保留完整映射。
- 新增 `InlineVector`／`VectorResource`，将调用方已生成的有界矢量轮廓及逻辑文字作为一个不可拆分对象，支持正文、表格、固定页区和流式路径。HTML／Markdown 图片占位符可通过显式资源注册映射到矢量，模型编辑、模板求值和重放保留对象与来源的原子绑定。
- 对符合条件的图文混排行保留原生 PDF 文字，改善常规提取器对中文表头的提取；同时修复字段／矢量原子标记长度与展开文字长度混用导致的后续链接偏移。原生路径限于 LTR、静态 TTF、无装饰、实际码点与 GID 逐一对应的安全整行，复杂塑形及含字段／矢量的行继续使用原轮廓路径。
- 只含 Fixed／Auto 列的语义表格为不可拆分的行内图片、字段及矢量保留内容下限，避免有可行列宽分配时仍被相邻长文字挤窄。显式最大列宽和页面空间仍须足够，跨列约束按真实覆盖区间处理。
- 字体载入、段落查找、PDF 字形映射、子集及 spool 资源继续采用有明确上限和生命周期的复用。JDK 物理字体加载改用私有 `FontData` 的独立只读游标，省去传入前的整份字节克隆；加载边界仍做防御复制，不改变文档、公式和图片质量。
- 公开文档站提供中英文指南、完整 API 侧栏和当前页面的语言切换，补充行内矢量 API 与实际接入说明。可选本地设计器继续在 Maven 库与 BOM 发布范围之外。

## 其他修复

- 完整布局与逐页入口统一累计脚注、正文和尾注的语义源预算，组件绘制累计计费并响应取消，避免通过分块或嵌套绕过已有工作上限。
- DOCX 路径写出使用同目录原子替换，失败保留原目标；取消与有界读取贯穿相关输入和转换路径。借用输出流仍由调用方拥有，失败可能留下部分字节。
- PDF 语义恢复保留阅读顺序；列表推断不补造缺失数字父项，混合缩进、跳级和零序号等不确定结构保留完整标记及正文并报告损失。
- 离线 PDF 信任验证可遍历多条候选证书链，逐条验证约束及匹配撤销证据；循环、搜索和证据工作共享有限预算并响应取消，不读取系统信任库或自动联网。
- 修复 SVG miter limit 一致性及设计器字体、资源历史、预览状态和表格手势；设计器的有界请求队列隔离上传、取消和静态资源请求。

## 兼容性与已知限制

- 公共 API 仍处于候选阶段。本轮 RC3 构建相对已发布 RC2 检查了 741 个可访问类型，结果为 0 项不兼容、28 项新增、0 项第三方类型泄漏。签名兼容不保证所有布局、提取顺序及渲染像素保持不变。
- 表头继续计入源行预算，例如 10,000 行正文加一行表头需要至少 10,001 源行额度；增加这一额度不会同时提高其他文字、绘制、资源或输出上限。
- 矢量入口不解析任意 TeX、SVG 或 MathML，不提供 TeX↔OMML 转换。PDF 用实际轮廓和 `ActualText` 保留逻辑文字，忽略该属性的提取器不保证能恢复原公式。DOCX／Web 默认拒绝矢量，只有明确 `INLINE_VECTOR`／DEGRADE 才保留逻辑文字并报告损失；XML v1 保存对所有策略均拒绝矢量。
- 生产依赖继续采用未修改的官方 PDFBox／FontBox 3.0.8，没有内嵌 FontBox 源码、定制同名类或可选补丁构建。字体内部快照和解析分配仍存在，`close()` 不代表仍被引用的堆数据立即回收。
- 缓存限额及源字节预算不等于实际堆或进程 RSS 上限。本次文献验收没有重新测量分配、耗时、堆、RSS 或容量，不提供固定提速、内存减半或普遍容量保证。

## 已有本地验证

本轮明确使用 `0.1.0-rc.3` 版本，完成 `build`、`sbom`、`publishLocalBundle` 及 production／capabilities／inlineVectors 样例生成。Java 测试报告合计 2,441 项，失败、错误及跳过均为 0；部分任务从 Gradle 构建缓存恢复，不将该数量描述为全部测试逐例重新运行。候选文档站 407 页生产构建通过。

本批新 SBOM 中 13 项第三方 Java 运行依赖在 2026-11-13 的 OSV 查询中没有已知公告命中。这是确切版本在查询时点的结果，不构成安全保证，也不覆盖未收录缺陷、原生载荷、字体、JDK 或构建工具。

开发版本接入批次已完成全仓构建、SBOM、本地 Maven 包和 API 检查，分别验证 Gradle 元数据、仅 POM 的 Gradle 消费以及真实隔离 Maven 消费。检查覆盖 16 个库及 BOM，48 个自研二进制／源码／Javadoc JAR 没有内嵌 FontBox；官方 FontBox 的 192 个类各只有一个提供者。临时密钥签名演练覆盖 82 项制品及篡改拒绝，该测试身份不是正式发布签名身份。

[独立矢量样例](../verification/inline-vectors.md)包含 1 页、3 个资源、8 次呈现，完成实际路径、基线、原子标记、PDFium 原 TeX 搜索／选区，以及 PDF 双引擎、SVG 和 PNG 全页对照；5 项负控制均被拒绝。它不替代任意公式或真实文献验收。

[两篇真实文献](../literature-pdf-integration.md#本次真实文献)共 17 页，保留 10 张表、26 个合并单元格、29 处公式 PNG 及 1 张原图；这 29 处公式没有转为矢量。27,077 个稳定字符框及 3,416 处源空白边界通过检查，三种提取器均恢复目标中文表头。Poppler／PDFium 共 34 次同引擎比较中，32 次全页像素相同；中文第 2 页保留明确记录的原生字形差异、表头提取顺序修正及一处最多 4 灰阶的旧空格淡像素差异。全部页面和差异已复查，没有将结果写成全文像素相同。

本轮本地 RC3 的 16 个库二进制 JAR 与上述 17 页验收批次逐项字节相同，合计 2,151 个 ZIP 条目、1,287 个类；因此复用该批次的 17 页结构、提取及双引擎渲染证据，没有将其描述为重新生成的文献验收。

RC3 新版本的 Gradle 元数据及仅 POM 两种隔离消费均通过。每种模式实际解析的 16 个库 JAR 均与本地候选制品 SHA-256 匹配，16 个库与 BOM 共 17 个项目组件均为 `0.1.0-rc.3`。新 API 验证任务从这些 JAR 编译并运行 `InlineVector` 样例，生成 PDF／SVG／PNG；两种模式共 4 份 PDF 完成真实路径、基线、逻辑文字及链接框的独立检查，最大几何误差约 0.00000125 pt，144 DPI 的 Poppler／PDFium、PNG 与 resvg 对照通过。

production 独立验收通过；capabilities 使用临时自签测试证书，通过 OpenSSL 实际验签及篡改拒绝，这不是 Maven 正式发布签名。发布工作流已配置生成并独立检查 inlineVectors 样例，隔离消费脚本包含新 API 验证任务；这些配置不表示远端工作流已运行。
