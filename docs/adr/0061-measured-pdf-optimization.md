# ADR-0061：可测量的 PDF 无损优化与显式图像降采样

状态：已接受。

## 决定

优化与页面编辑分开。原流无过滤或仅一层 Flate 时保留 predictor 参数，仅在更小时替换 DEFLATE 编码；压缩候选不更小即放弃，不吞掉真实解码／预算失败。只去重属性和编码完全相同的简单图片及 TrueType 程序流；保留源关系和被动对象。

图片缩小是独立、默认关闭的损失路径。显式像素上限、固定比例、双三次插值；JPEG 编码另需授权。全图遍历先识别蒙版引用，蒙版和含蒙版图片不独立缩小，避免透明关系损坏。

预检的内容解析使用不修改源字典的视图；不得借 Form 构造器向页面流写入 Subtype。连续页面流按整体检查 q/Q 平衡，真正 Form 仍独立检查。资源条目的任意名称不能被误当为批注动作键。

## 验证

确切编码、统计和损失报告在目标写入前生成；最终再次验证结构。证据见[阶段五十三](../verification/phase-53-pdf-optimization.md)，公共契约见 [API](../pdf-optimization-api.md)。不保证输出一定更小。
