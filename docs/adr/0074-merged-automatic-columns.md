# ADR-0074：合并格覆盖有界自动宽度列

状态：已采纳。

## 决策

普通语义表格允许横向／纵向合并覆盖 `ColumnWidth.Auto`。单列锚点先按原算法计算首选宽度；横跨固定／自动列的格按跨度、源行、物理列固定顺序施加首选宽度约束，只对自动列的剩余容量按比例增长。探测宽度不超过页面，内边距按真实锚点只扣一次。

含比例列的合并区使用最终剩余宽度，不额外把同一格的首选宽度重复分配给自动列。最终自动宽度仍可向显式最小值收缩，比例列分享余量；不保证内容所需最小字形宽度，过窄文字仍明确失败。需要确定尾列宽度时使用固定列。

探测不计源文字、诊断或输出行，最终测量仍使用真实合并宽度并保留行列／UTF-16。仅纵向合并不改变列宽推导。旧固定／比例组合和未合并自动列保持。

块格及内表的 Auto 仍有独立限制；单向源没有未来全表，不能由本项获得自动列宽。DOCX 写标准跨度及既有 Auto 描述，不承诺 Word 使用相同的首选宽度算法。
