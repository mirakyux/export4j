# ADR-0115：源内容块在编写边界解析并逐属性继承

- 状态：已采纳；本批实际验收另行记录
- 日期：2026-11-13

## 背景

同一份文档需要将数据库字段、静态文字、Markdown 和 HTML 按块组合，并让各块独立声明字体、颜色、段落几何以及公式／表格解析行为。既有主题、组件作用域及离线导入器已有明确契约；不能通过默认数值猜测省略属性，也不能在布局／后端重新解释普通字符串。

## 决定

在模型层增加不可变编写声明 `ContentOptions`，逐项保存段落属性、字体角色和 RGB 的声明意图。零值、黑色、空角色和 `false` 均为显式声明。`Format` 使用互斥的 `INHERIT/TEXT/MARKDOWN/HTML`，公式与表格分别使用三态开关。`Resolved` 保存完整值，不允许残留继承。单元格及表格完整格式仍以完整值替换，不引入另一套通用 CSS。

`DocumentTemplate.Source` 是模板节点，不是最终 `Block`。静态源原样保存；动态源只允许选择一个完整字符串字段，不允许混合模板插值。解析产物的文字、链接和矢量阅读文字不再插值。已完成的 `Paragraph`／`Table` 和 `add(Block)` 保持原有完整值语义，布局与后端不执行解析。

核心只定义同步 `SourceContentParser` 契约。`ContentImporter` 在 Web 适配器中复用受支持的离线 Markdown／HTML 语法，固定采用严格损失策略，资源按精确键显式登记。公式由可选 `FormulaProcessor` 装配；`export4j-math` 提供 `TexMath.processor()`，不要求使用端维护通用识别／渲染器，也不让核心反向依赖公式实现。

XML 的根默认值、词法 `scope` 和单个 `content` 共同使用同一声明模型。根／作用域的排版默认值贯通原生文字块；源格式及解析开关只控制 `content`，旧 `p`／`span` 保持既有文本与插值契约。正文单元格通过模板 `CellContent` 展开源／条件／循环，最终仍是已有块格。重复表头中的块式源内容及同格 `style-if` 混用明确拒绝。

`Caption` 和 `CrossReference` 保存显式 `TextAppearance`，编号／引用降到最终文字时保留外观；兼容构造器继续选择默认角色和黑色。没有给任意语义段落新增背景、边框或隐式字体资源。

## 预算及生命周期

每次 render 对同一解析器身份打开一个任务内 session，跨源块、循环、分节和单元格累计源输入、语法树／工作量、表格、公式与矢量预算。每次调用同时取得模板剩余输出额度；解析器先约束中间分配，模板再独立检查最终树、命名空间及剩余预算。进入子块不重置额度。

成功、失败及取消均同步关闭 session，主异常与清理异常保留。解析器不得隐式访问文件／网络，不得保留文档对象。保守输入复杂度预留不能称为强制内存／CPU 沙箱；第三方解析仍受已声明子集及执行边界约束。

## 备选与代价

- 在每个最终 `Block` 中增加解析开关：会使完成的语义模型携带编写语法，要求布局、保存和后端重复解释，未采用。
- 同时使用多个 HTML／Markdown boolean 并自动猜格式：优先级及普通文本含义不明确，未采用；源格式互斥，公式和表格开关独立。
- 用 12 pt、黑色、空角色等默认数值推断未声明状态：破坏显式声明和单项恢复，未采用。
- 先拼接模板字符串再解析任意富文本：会重新解释普通字段和已解析链接／阅读文字，未采用；富文本字段选择必须明确且完整。
- 每个源块新建一组预算：循环可绕过总量限制，未采用；session 与模板预算跨调用累计。
- 为统一入口自动容忍损失：会把未知语义静默展平，未采用；需要损失政策的通用导入继续使用原适配器入口。

源块编译需要中间语法树和最终块；它不等于按页流式源，也不提供任意网页、完整 LaTeX 或通用模板沙箱。已解析模型可以继续交给现有输出与显式损失处理，但公式矢量不因此变成跨格式的原生公式语义树。
