# ADR-0081：行内内容内表复用有界自动列宽

状态：已采纳。

## 背景

核心自动列宽算法已经接受当前表的实际 availableWidth，但嵌套入口统一拒绝 Auto，导致固定／比例父格内的普通文字表也无法使用。直接测量过程的预算和来源贯通已有；含块格表的首选宽度尚无定义，应继续保持独立限制。

## 决策

移除仅因嵌套而拒绝 Auto 的检查，继续拒绝 Auto 表自身的块格。复用同一有界测量／合并约束／最小值收缩算法，实际输入为父格内容宽度。首选探测统一补齐当前锚点的 CellLocation；不重置文档预算，不产生单独布局引擎或新的分页算法。

DOCX 同步允许行内内容内表的 Auto 声明，使用原有标准网格及自有 min／max 元数据；含块格 Auto 表及重复表头 PAGE 拒绝保持。Word 独立重排，不由元数据或原生字段存在推断视觉一致。

## 结果

原子内表与递归续排可使用有界 Auto，横纵合并、最终字段和链接保持既有来源。最小宽度不适配、缺字、预算及取消继续显式失败；单向 Auto、含块树的 Auto 与变宽递归子树续排不由本决策引入。
