# ADR-0116：标题与列表保留混合内容，XML 保存静态矢量

- 状态：已采纳；本批实际验收另行记录
- 日期：2026-11-13

## 背景

已有 `Paragraph` 以 U+FFFC 和原始 UTF-16 索引保存行内图片、字段及矢量。标题和列表只保存文字运行，导入器遇到相同混合内容时必须拒绝或损失对象；模板绑定、列表前缀、编辑、保存和恢复也容易只复制文字。与此同时，矢量的不可变几何已有完整边界，但 XML v1 尚无静态编码，无法通过普通资源 ZIP 完整保存这类模型。

## 决定

`Heading`、`BulletItem`、`NumberedItem` 与段落使用相同的 `ImageSpan`／`FieldSpan`／`VectorSpan` 结构，提供 `mixed(...)` 和完整 `paragraph()` 投影。列表 Builder 的 `content(...)` 立即快照输入；最终字号只重建内部对象占位样式，不改写显式文字运行、字段样式和对象值。旧构造器保留，默认为空对象列表；新增 record 组件会影响源码中的 record 解构模式，调用方须重新编译并调整组件数。

前缀插入、模板绑定和模型编辑复用完整混合内容，不通过拼接 U+FFFC 字符猜测对象，也不把公式阅读文字当作原始字符长度。图片、字段、矢量各占一个原始 UTF-16 单元，绑定普通文本后重新确定其位置。矢量阅读文字与几何作为同一值保存，不能分别插值。

XML v1 增加静态 `vector` 和 `segment` 编码，记录宽度、ascent／descent、阅读文字、RGB、路径操作及坐标。路径通过既有 `VectorResource` 校验，不能引用文件、URL 或可执行绘图回调。`logical` 始终为字面值；外围显式链接继续使用原有被动链接规则。`XmlTemplateWriter` 在严格策略下完整保存路径，无须把矢量变成图片或隐藏源副本。

自动标题导航组合文字、图片 alt 和矢量阅读文字；动态字段没有静态值，须使用明确的书签标题。标题拒绝脚注标记，列表保留有匹配注释的显式标记。无障碍模型桥接未定义混合对象结构时显式拒绝，不以新增 `mixed` 入口声称任意组合已具备 PDF/UA 支持。

## 预算与生命周期

模型继续采用不可变资源快照和有限标记数量。XML 编译保留输入、深度、元素和文字预算，单个路径最多 10,000 段；绑定继续累计阅读文字及段数。保存和 ZIP 编码继续采用现有节点、资源和输出字节上限，失败时不覆盖旧路径。布局计入标题的图片／矢量资源及逻辑文字，列表降为完整段落后沿用同一检查。

本决定不引入全局路径缓存、字体发现、后端句柄或跨文档可变状态。几何及阅读文字的保存不等于公式语义树；普通矢量在 DOCX／Web 中仍按现有显式损失契约处理。可编辑数学的表示由专门公式接口负责。

## 备选方案

- 标题／列表继续转成普通段落：会丢失标题层级、列表身份和独立标记样式，未采用。
- 遇到对象一律替换为逻辑文字：会把保真缺口转为不可见的图形损失，未采用。
- 给每种语义块分别实现独立对象模型：会重复来源、预算和编辑契约，未采用；使用已有段落结构及投影。
- 在 XML 中保存任意 SVG 或绘图脚本：扩大解析、资源访问及安全边界，未采用；仅支持已有有限路径操作。
- 对 `logical` 单独执行模板插值：可能使阅读文字和真实轮廓不一致，未采用；动态公式须整体重建。

## 验证方式

模型回归覆盖 Unicode 绑定、UTF-16 迁移、对象替换和 Builder 快照。组件回归检查标题／两种列表的真实图片／矢量呈现、外链、跨页及前缀偏移，列表脚注不重复追加。XML 回归检查严格保存、三轮 ZIP 重开、非法路径、未知属性及字面阅读文字。公共入口还须经过完整构建、隔离消费和实际输出检查，结果见[富内容验收](../verification/rich-content.md)；本决定的采纳状态不代替验收通过。

使用方式及边界见[行内矢量 API](../inline-vectors-api.md)与[源内容块 API](../content-blocks-api.md)。
