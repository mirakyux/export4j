# ADR-0111：普通文档按页规划、重放与释放

- 状态：接受；验收证据独立记录。
- 日期：2026-11-06。

## 背景

普通文档的完整布局入口保留全部 Layout IR，绘制入口返回全部 Display List。只换成磁盘 PDF 后端不能释放这两层结果。需要保留总页数、目录、分节页码、未来引用及脚注，同时让导出调用方不必持有完整布局结果。

## 决策

保留现有 `layout`／`export` 的完整返回值，新增 `DocumentEngine.exportPaged`，接受普通、带语义页区及分节文档。请求选择 `PageBackend`，返回页数、诊断计数和写出字节等轻量摘要。核心分页仍使用 `DocumentLayouter` 的原有 Flow，通过同步页回调交付；页绘制会话复用有界图片及边框缓存，消费后释放页面和已消费块的测量缓存。

组件层先规划最终分页及导航，再重放逐页解析字段、绘制、合成页区和输出。规划保留紧凑目标、节页数和脚注分配，不保留全部正文页面。目录偏移、物理页索引与显示页码分别处理。所有遍历在调用线程执行，预算、取消及异常继续沿现有执行上下文传播。

自定义组件必须可以确定性重测；重放核对规划结果，变化使整次导出失败。固定页区以实际最终总页数合成。页面 SPI 无评论及可编辑字段通道，非空声明在打开写出器前拒绝，不能静默丢弃。

`PdfSpoolBackend` 保留普通渲染器的保存步骤以完成字体子集化，并以有界丢弃流测量单页序列化字节；保存后直接复制仍存活的页对象图，不再写入和重新解析单页 PDF。复制结束才关闭单页文档并解除字体程序固定。原单页字节预算保持，临时工作预算继续保守计入该页的序列化等价大小，磁盘只保存索引。

## 边界

输入模型仍由调用方完整持有；最大单块、长表、组件准备结果及 keep 链可能随块规模增长。唯一 ID、锚点、导航与脚注索引受预算限制，但不是恒定大小。逐页入口减少完成页的中间对象保留，不能据此声称任意输入恒定内存。

普通 `PdfBackend` 的文档级 PDFBox 状态仍会累计；需要逐页释放格式对象时显式选择 `PdfSpoolBackend`。后者继续只支持普通 PDF，不扩展归档、加密、签名或无障碍认证范围。输出流借用，失败可留下部分字节；路径入口同目录原子替换，失败保留旧目标。

API 见[逐页文档导出](../paged-document-api.md)，原行源入口见 [ADR-0102](0102-bounded-semantic-streaming-replay-and-pdf-spool.md)。
