# ADR-0064：有界 PDF 语义恢复

状态：已接受。

## 决定

在 PDF 适配器内部新增独立语义导入通道，结果为后端中立的 SectionedDocument 和块级来源框。普通读页、原对象编辑与语义恢复使用不同契约；不让布局核心读取 PDFBox 对象，也不由页面复制推断可编辑文档结构。

首版按水平可见字形的基线／X 组成行，每行一个段落，按页内字号中位数推断两级标题，块按 Y／X 排序。表格需要调用方显式提供全部网格边界，不能切字或与图片相交；图片恢复为保留解码像素及显示大小的流块。文字来源框是字体度量近似，不可用作精确脱敏框。

默认拒绝所有推断损失。调用方明确接受 PDF_LAYOUT／DEGRADE 后仍逐项处理字体映射、路径、隐藏文字、替代逻辑文字及原交互／元数据的损失。只接受零旋转普通页面、嵌入静态 TrueType 和明确内容结构；不获取字体或外部资源，不执行 OCR。空白页不生成 section，全部没有可恢复内容时失败。

导入候选不可变，配置在转换入口快照，统一导入→编辑→编码预检沿用既有 DocumentConversion。真实字形、操作符、网格工作量、节点、像素及编码预算保留；策略不能绕过权限、签名、非法结构、取消或 I/O。目标格式损失与源恢复损失分别报告。

## 验证

行为回归覆盖内容／结构、明确网格、切字拒绝、字体映射、不可忽略边界、取消、配置快照及报告对账；独立检查原生 OOXML、HTML、Markdown、图片像素、重新布局 PDF 和全部双渲染页面。见 [API](../pdf-semantic-import-api.md)及[阶段五十六](../verification/phase-56-pdf-semantic-import.md)。
